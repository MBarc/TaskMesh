# Installer Assets

Place the following files in this directory before running `build.ps1`.

---

## Required

### `taskmesh.ico`
The application icon used for the installer EXE, Start Menu entry, and desktop shortcut.

- **Format:** `.ico` (Windows icon)
- **Recommended sizes:** 16×16, 32×32, 48×48, 256×256 (all in one multi-resolution `.ico` file)
- **Design:** Buzz the bee on a deep indigo background (`#1E1B4B`)
- **Dominant color:** Golden yellow (`#FCD34D`)
- **Tool:** Export from Figma / Illustrator using a Windows ICO exporter, or use [GIMP](https://www.gimp.org/) / [IcoFX](https://icofx.ro/)

### `LICENSE.txt`
Plain-text license file shown on the License wizard page.

- **Format:** plain UTF-8 text, Windows line endings (`\r\n`)
- **Content:** Your EULA or a reference to https://taskmesh.co/license

---

## Optional (enhanced installer visuals)

### `banner.bmp`
Displayed in the top area of inner wizard pages.

- **Format:** BMP (24-bit)
- **Size:** 497×58 px (Inno Setup default for `WizardImageFile`)
- **Design:** TaskMesh logo + "Buzz toward done" on indigo (`#1E1B4B`) background

### `welcome.bmp`
Full-height image shown on the Welcome and Finish pages (left sidebar).

- **Format:** BMP (24-bit)
- **Size:** 164×314 px (Inno Setup default for `WizardSmallImageFile`)
- **Design:** Buzz mascot (happy mood) centered on indigo background, golden accents
