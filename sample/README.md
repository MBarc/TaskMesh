# Sample Directory

This directory contains example files and templates for TaskMesh.

## Contents

- **meeting-transcripts/** - Meeting transcripts to test the AI's ability to extract actionable items from.
- **documentation/** - Example project documentation files
- **documentation-templates/** - Reusable templates for creating new documentation

## Purpose

Use these samples as references when creating your own content in TaskMesh. They demonstrate recommended formatting, organization patterns, and best practices.
